## Trabalho Unifecaf POO

Sistema de gerenciamento de orçamentos imobiliários, com operações executadas em terminal. Projeto desenvolvido como trabalho acadêmico no curso de Tecnólogo em Ciência de Dados - Unifecaf.

---

### Setup

1. Clone o repositório:
```
git clone https://github.com/MthLeal/trabalho_unifecaf_poo.git
```

2. Instale as dependências:
```
pip install -r requirements.txt
```

3. Execute o programa (localmente):
```
python main.py
```
